# 마비노기 모바일 음성 채팅

**말하면 그대로 게임 채팅으로 나간다.** 타자를 치지 않아도 된다.

```
(마이크에) "파티 구해요 던전 같이 가실 분"
        ↓
게임 채팅창에  파티 구해요 던전 같이 가실 분
```

말소리를 알아서 감지한다. 말을 시작하면 녹음하고, 잠깐 조용해지면 한 마디가
끝난 것으로 보고 글로 바꿔 보낸다. 버튼을 누르고 있을 필요가 없다.

## 필요한 것

| | |
|---|---|
| 운영체제 | 윈도우 10 또는 11 |
| 마이크 | 아무 것이나. 헤드셋 마이크로 충분하다 |
| 게임 | 마비노기 모바일 **PC 클라이언트** |
| 그래픽카드 | 없어도 된다. NVIDIA 가 있으면 훨씬 빠르다 |
| 디스크 | 1.5 ~ 4 GB (고르는 모델에 따라) |

파이썬을 미리 깔 필요는 없다. 프로그램이 자기 것을 따로 들고 온다.

## 설치

### 1. 게임에서 먼저 켠다

게임 설정에서 **MM AI 에이전트 활성화** 를 켠다. **이걸 켜지 않으면 채팅을
보낼 수 없다.** 켜면 게임이 필요한 파일을 알아서 깔아 준다.

### 2. `실행.bat` 을 두 번 누른다

첫 실행은 준비하는 데 시간이 걸린다. 한 번만 겪으면 된다.

| 받는 것 | 크기 | |
|---|---|---|
| 파이썬 | 45 MB | 이 프로그램 폴더 안에만 들어간다 |
| 필요한 꾸러미 | 약 400 MB | 음성 인식에 쓰는 것들 |
| GPU 가속 | 550 MB | NVIDIA 그래픽카드가 있을 때만. 받을지 물어본다 |
| 음성 인식 모델 | 0.5 ~ 3 GB | 창에서 고른 것 |

이미 쓰고 있는 파이썬이 있어도 건드리지 않는다. 이 프로그램은 자기 폴더
안에서만 산다.

### 3. 처음에는 연습 모드로 해 본다

창의 **설정** 탭에서 **연습 모드**를 켜고 말해 본다. 인식은 하지만 채팅으로
보내지 않으므로, 말이 어디서 끊기는지 안전하게 확인할 수 있다. 감이 잡히면
연습 모드를 끈다.

## 쓰는 법

- **말하면 나간다.** 보내기 전에 확인하는 단계는 없다.
- **Win+F9** 로 듣기를 켜고 끈다. 게임이 앞에 있어도 먹힌다.
- 창을 **닫거나 최소화하면** 작은 표시창으로 내려간다. 완전히 끄려면
  작업표시줄 트레이 아이콘에서 **종료**.

> **자리를 비울 때는 꼭 듣기를 끈다.**
> 켜 둔 채로 두면 방 안에서 하는 모든 말이 공개 채팅에 그대로 올라간다.
> 통화나 혼잣말도 마찬가지다. 되돌릴 수 없으니 습관을 들이는 편이 좋다.

### 창

위쪽 칸은 늘 보인다. 지금 듣는 중인지, 어떤 단축키를 쓰는지, 그리고 음량
막대가 있다. 막대의 **초록은 지금 들어오는 소리**, **주황 선은 말소리로
인정하는 문턱**이다. 초록이 주황을 넘으면 녹음이 시작된다.

아래는 **기록** 과 **설정** 두 탭이다.

| 설정 항목 | 무엇 |
|---|---|
| 마이크 | 장치를 바꾸면 곧바로 바뀐다 |
| 모델 | 아래 「모델 고르기」 참고 |
| 단축키 | 버튼을 누른 뒤 원하는 조합을 누르면 바로 바뀐다 |
| 민감도 | 주변 소음의 몇 배를 말소리로 볼지. 게임 소리에 헛발질하면 올린다 |
| 말끝 기다림 | 이만큼 조용하면 한 마디가 끝난 것으로 본다. 말이 잘리면 늘린다 |
| 연습 모드 | 인식만 하고 보내지 않는다 |

### 작은 표시창

창을 내리면 화면 위에 작은 표시창이 뜬다. 점 색과 글자로 듣는 중인지 보이고,
옆의 얇은 막대가 지금 음량이다.

| 조작 | 하는 일 |
|---|---|
| 끌기 | 자리를 옮긴다. 옮긴 자리를 기억한다 |
| 왼쪽 클릭 | 큰 창을 다시 연다 |
| 오른쪽 클릭 | 듣기를 켜고 끈다 |

전체화면을 **독점 방식**으로 쓰는 게임 위에는 뜨지 않는다. 테두리 없는 창
모드로 하면 잘 보인다.

### 단축키 바꾸기

**설정** 탭의 **키 바꾸기** 를 누르고 원하는 조합을 그대로 누른다. Win 을
섞어도 된다. Esc 로 취소되고, 8초 동안 아무 키도 누르지 않으면 저절로
취소된다. 바꾸면 그 자리에서 바로 적용된다.

쓸 수 있는 키는 F1~F12, A~Z, 0~9, 스페이스, Insert, ScrollLock, Pause 이고
여기에 Win · Ctrl · Shift · Alt 을 섞을 수 있다.

## 모델 고르기

말을 글로 바꾸는 부분이다. 큰 것이 정확하지만 무겁다.

| 모델 | 크기 | 한국어 | 쓸 곳 |
|---|---|---|---|
| tiny · base | 0.1 GB | 나쁨 | 잘 안 쓴다 |
| small | 0.5 GB | 보통 | **그래픽카드가 없을 때** |
| medium | 1.5 GB | 좋음 | 무난 |
| large-v3-turbo | 1.6 GB | 매우 좋음 | **대부분 이걸 권한다** |
| large-v3 | 3.1 GB | 가장 좋음 | 그래픽카드 메모리가 넉넉할 때 |

처음 실행하면 이 PC 형편을 보고 하나를 골라 준다. 그대로 써도 되고 바꿔도
된다. **설정** 탭에서 고르고 **내려받기** 를 누르면 진행률이 보인다.

100% 에 닿은 뒤 잠깐 「받은 파일을 맞추는 중」 이 붙는다. 조각으로 받아 온
파일을 하나로 합치는 단계다. 멈춘 것이 아니니 기다리면 된다.

한 번 받은 모델은 계속 쓴다. 판을 올려도 다시 받지 않는다.

**그래픽카드가 없으면 `small` 을 쓴다.** 큰 모델은 말보다 인식이 한참 늦어서
대화에 쓸 수 없다. 창이 그 사실을 알려 준다.

## 알아 둘 것

### 못 하는 일

- **채팅을 읽지 못한다.** 게임이 읽는 기능을 열어 주지 않았다. 그래서 남의
  말에 자동으로 답하는 것은 불가능하다. 이 프로그램은 **내 말을 보내는**
  것만 한다.
- **채널을 고를 수 없다.** 게임에서 지금 열어 둔 채팅창으로 나간다. 길드로
  말하려면 게임에서 채널을 길드로 바꿔 둔다.
- **한 줄은 50자까지다.** 말이 길면 여러 줄로 쪼개 조금씩 띄워 보낸다.
- `/` 나 `#` 로 시작하는 말은 게임이 명령으로 보고 거절한다. 그래서 첫 글자가
  그 둘이면 떼어내고 보낸다.

### 잘못 들을 수 있다

음성 인식은 반드시 틀릴 때가 있다. 확인 단계가 없으므로 잘못 들은 말이 그대로
공개 채팅에 올라간다. 아래는 걸러내지만 완벽하지는 않다.

- 0.4초 미만의 짧은 소리 (기침, 마우스 클릭)
- 침묵에 붙는 헛문장 ("구독과 좋아요" 같은 것)
- 같은 글자만 반복되는 인식 실패
- 5초 안에 같은 말이 두 번 잡힌 중복

보낸 말은 모두 `sent.log` 에 남으니 나중에 되짚을 수 있다.

## 문제가 생기면

### 창이 안 뜨거나 바로 닫힌다

`콘솔로_실행.bat` 으로 띄운다. 검은 창에 무엇이 잘못됐는지 나온다.

### 게임 조작 프로그램을 찾지 못했다고 한다

먼저 게임 설정의 **MM AI 에이전트 활성화**가 켜져 있는지 본다. 켜 두었는데도
그러면 **설정** 탭 맨 아래 「게임 조작 프로그램」에서 순서대로 해 본다.

1. **다시 찾기**
2. **디스크에서 찾기** — 게임을 흔하지 않은 곳에 깔았을 때. 최대 30초
3. **직접 지정** — `MabinogiMobile_CLI.exe` 를 직접 골라 준다. 게임 설치
   폴더에 있다. 한 번 지정하면 기억한다

### 채팅이 두 번씩 나간다

프로그램이 두 개 돌고 있는 것이다. 트레이 아이콘이 두 개인지 본다. 창이 안
보여도 배경에서 듣고 있을 수 있다. 하나를 종료하면 된다.

### 단축키가 게임 안에서 안 먹힌다

`관리자로_실행.bat` 으로 띄운다. 게임과 같은 권한이 되어 키가 전달된다. UAC
확인 창이 한 번 뜬다.

다른 프로그램이 같은 조합을 쓰고 있을 수도 있다. 그럴 때는 **설정** 탭에서
다른 조합으로 바꾼다.

### 인식이 느리다

그래픽카드를 쓰지 않고 있을 가능성이 크다. NVIDIA 그래픽카드가 있으면
`GPU로_바꾸기.bat` 을 한 번 실행한다. 없으면 모델을 `small` 로 내린다.

### 말이 중간에 잘린다 / 안 한 말이 나간다

**설정** 탭의 두 값을 만진다.

- 말이 잘리면 **말끝 기다림** 을 늘린다
- 게임 소리나 잡음에 헛발질하면 **민감도** 를 올린다

## 판을 올릴 때

**옛 폴더에 그대로 덮어쓰면 된다.** 모델과 설정은 그대로 남는다.

내 것(모델·설정·보낸 말 기록)이 있는 자리는 이렇게 정해진다.

| 경우 | 자리 |
|---|---|
| 프로그램 폴더에 `models\` 나 `settings.json` 이 이미 있으면 | 프로그램 폴더 |
| 그 밖에 (새로 깐 경우) | `%LOCALAPPDATA%\mabi-voice-chat` |

환경변수 `MABI_DATA` 로 자리를 직접 정할 수 있고, 모델만 따로 두려면
`MABI_MODELS` 를 쓴다.
